# Scientific assessment

The frozen experiment supports the tested training--learning mechanism chain
and frozen-inference projection relation in a routed expert system. This is
stronger than a performance replication because the experiment directly
intervenes on receiving parameter states, Adam memory, realized-update
amplitudes, expert coalitions, routing, trained component versions and restored
versions under an identity-preserving GFG record.

The supported relations are:

1. The same realized update produces different functional responses in
   different receiving parameter states, and changing Adam memory also changes
   the response.
2. Complete response paths include saturating, accelerating, turnback and
   sign-reversal forms, establishing finite-amplitude nonlinearity.
3. Functional support is distributed over routed experts and is persistently
   reallocated by actual training updates.
4. Target-boundary outcomes remain prospectively predictable on held-out runs
   from the adapted response coordinates without reading post-update outputs.
5. Frozen inference preserves model and optimizer state while queries recruit
   different routed supports, expert contributions combine non-additively and
   rollback to pre-learning expert or router versions changes the result.

Two qualifications are important. First, F3 supplies most of the held-out
predictive gain; the current F5 summary does not improve F1+F3 even though
native Adam-memory exchange establishes a causal optimizer-memory effect.
Second, boundary-changing transitions are rare in these single-update records,
so their high direct-prediction recalls have limited denominators. Neither
qualification changes the pre-registered pass/fail verdict, but both constrain
interpretation.

The correct conclusion is bounded cross-system support in the executed compact
Vision-MoE. It is evidence that the relations are not peculiar to dense
Transformers, ResNets or diffusion U-Nets. It is not unconditional proof for
all MoE routing algorithms, expert counts, datasets or training regimes.
