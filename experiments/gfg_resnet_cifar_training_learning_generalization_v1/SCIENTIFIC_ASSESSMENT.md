# Scientific assessment

The formal experiment supports cross-system generalization of the tested
training--learning mechanism chain. The evidence is stronger than a simple
performance replication because the system changed architecture, modality,
task and optimizer together, while the same pre-response relations remained
measurable and predictively useful.

The supported relations are:

1. A realized training update does not determine its functional result by
   itself. The current receiving parameter state changes the response, and
   SGD momentum memory changes it in most frozen exchanges.
2. Complete target responses include saturating, accelerating, turnback and
   sign-reversal paths, so finite-amplitude nonlinearity is present outside the
   original nanoGPT system.
3. Functional capacity is distributed across residual stages, and a realized
   update reallocates that support rather than merely changing a single fixed
   component.
4. Target-boundary outcomes can be predicted before post-update outputs are
   read, and the adapted F1/F3/F5 coordinates outperform F1 alone on complete
   held-out runs.

The most important qualification concerns F5. Native receiving-memory
exchanges establish a causal role for SGD momentum, and momentum permutation
damages held-out prediction. However, the present F5 summary does not improve
the run-isolated F1+F3 model. The evidence therefore supports optimizer memory
as part of the receiving state, but does not establish that this particular
low-dimensional F5 representation is already sufficient or optimally used.

The correct scientific conclusion is not unconditional universality. It is
that the theory's primary formation relations transport from
nanoGPT/Transformer/text/Adam to an independently executed
ResNet-18/image-classification/SGD-momentum system, surviving frozen integrity
checks, negative controls and complete-run holdout prediction.
