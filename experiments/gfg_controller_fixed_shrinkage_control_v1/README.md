# 固定缩放与目标边界动态控制：严格配对对照

基线 `ab10b96129c3139d3fa4c50532a474aebfeeeca9`。仅新增本实验目录，原实验、main、正式冻结标签和旧证据不变。

## 判定

ADAPTIVE VALUE SUPPORTED IN AGGRESSIVE REGIME

大步长控制器定位与本轮证据一致：True。
判据预先封存：达标数不减、平均限制步数下降、至少两个历史获益，且逐一移除任一历史仍保持达标数不减和平均步数下降。
这是已有 witness family 上的描述性稳健性要求，不是总体显著性检验。只比较四档常数，不声称胜过所有学习率或调度。

具体支持范围是 **LR=0.003**：动态控制6/7达标，留一固定缩放5/7达标；平均限制步数
94.714降至58.143（减少38.61%），逐历史5胜1负1平，移除任一历史仍通过预定稳健性检查。
这说明本轮动态收益不能由所比较的留一固定缩放策略完全复制，但没有排除所有时变调度解释。

**LR=0.01不支持同样结论**：固定缩放5/7达标、113步，动态4/7达标、114.857步。
LR=0.001也没有总体优势。不能概括为“越大的学习率，动态控制越好”。

步数优势不等于时间优势：LR=0.003动态含核验平均时间0.983226秒，固定缩放0.780640秒，
本轮动态控制仍比固定缩放慢。三档计时均完整保留。

## 设置

同12个历史权重、原始有序批次和212个带标签控制/评估目标；fresh fused AdamW、零weight decay、norm1裁剪、FP32、三档cosine基础LR。
固定α=1/.75/.5/.25与原动态控制器，动态每5步刷新；moments保持原生递推，不乘α。固定缩放在精确算术下等价于同比缩小LR，本实验保持native proposal后缩放的确切浮点顺序。
留一只用于固定α选择，不是未见目标泛化；212个目标也被控制器使用。各LR都进行180份搜索中的相应部分及三次精确重放计时，总计324份计时记录。
首次达到99%即停止，失败200步计入；95%为次要指标，初始已达标者分别排除。搜索成本另计。
