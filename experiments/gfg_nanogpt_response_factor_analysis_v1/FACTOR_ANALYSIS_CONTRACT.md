# 逐目标有限幅度非线性响应的前置条件因子分解合同

状态：`FROZEN_BEFORE_FACTOR_RESULTS`

本合同冻结于读取任何本轮因子分解结果以前。本轮只使用12个开发运行、72个既有有限幅度响应section及其已经形成的前态、真实更新和过去事实。全局未见运行 `entry-362ded584a953f360aec` 不得访问。本轮不训练端点预测器，也不产生新的nanoGPT训练轨迹。

## 1. 分析单位与身份

分析单位是一个具体section中的一个评价目标响应。目标身份必须由 `evaluation_unit_id`、`row_content_sha256`、`upstream_element_identity` 与 `target_group` 建立；数组位置仅用于读取已由身份材料绑定的载荷，不得作为跨运行身份。

跨运行相同语义目标的主键为 `(row_content_sha256, target_group)`。`entry_id`、`run_id` 与绝对optimizer step只用于分折、聚类、审计和查找历史，不得作为解释变量或距离特征。

## 2. 响应表示

冻结幅度网格为 `[-0.125, 0, 0.125, 0.25, 0.5, 0.75, 1]`。

每个目标保存：原始margin曲线、相对alpha=0位移、以最大绝对位移加 `1e-12` 归一化的形态曲线、alpha=1端点位移、相对0到1直线插值的非线性残差、竞争者换手、首次换手幅度、换手次数、最终竞争者、首次过零幅度与正确/错误转换类别。

主要连续形态指标为去除alpha=0后的归一化形态Pearson相关性，同时报告归一化形态RMSE、原始位移相关性与端点位移绝对差。零方差相关性记为未定义，不以零替代。

响应类型按以下冻结优先级判定：

1. `TURNBACK`：相邻有限差分在超过总位移5%的有效斜率中出现符号翻转；
2. `SIGN_REVERSAL`：正幅度初段响应与alpha=1端点位移符号相反；
3. `NEAR_LINEAR`：相对0到1直线的归一化残差RMS不超过0.10；
4. `SATURATING`：最后两段平均斜率绝对值不超过最初两段平均斜率绝对值的0.50；
5. `ACCELERATING`：最后两段平均斜率绝对值至少为最初两段的2.0；
6. `PIECEWISE`：最大相邻斜率跳变量至少为斜率绝对值中位数的2.0；
7. `OTHER`。

## 3. 前置条件块

- `F1_boundary`：alpha=0 margin、正确状态、正确logit、前三竞争者logit、竞争拥挤度及距边界程度。
- `F2_competitor`：最强及前三竞争者身份和间隔、近似并列标志、当前步骤以前最近一次竞争者换手。
- `F3_update`：真实参数更新总幅度、四组件幅度/份额/集中度，以及输出嵌入中正确类和当前竞争类对应行的更新幅度、差异、余弦与抵消量。需要额外本步功能探针的对齐量标为 `DIAGNOSTIC_PROBE_DERIVED` 并从自然条件主分析排除。
- `F4_support`：alpha=0时目标组的necessity、backup、allocation、concentration、effective support、single/double failure slack、主支撑及备用结构；另保留section级全局摘要。
- `F5_optimizer`：响应形成前的四组件parameter RMS、Adam一阶矩RMS、二阶矩平方根均值、preconditioned RMS及其不均衡与交互摘要。
- `F6_native_history`：当前步骤以前1至5步的同一身份目标margin、正确状态、竞争者、支撑、能力及真实更新摘要。缺失历史必须显式标记，不得填补。
- `F7_prior_curve`：仅使用同一冻结相邻对中已经完成的前一section曲线。F7只在36个后段section上定义，并与F6分开。

F4来自已经完成的CSRG前置诊断探针，必须标记为 `PRETARGET_DIAGNOSTIC_STATE`；它不是普通训练天然字段。F7来自过去主动响应实验，必须标记为 `PRIOR_ACTIVE_DIAGNOSTIC_MEMORY`。

## 4. 标准化和块距离

连续特征以12个开发运行中的前置特征分布进行中位数/IQR标准化；IQR小于 `1e-12` 的特征删除并记录。缺失历史数值以标准化后的零值参与距离，同时增加独立缺失指示，并在结果中报告；该操作只定义距离，不把缺失历史伪造成观测值。分类特征采用精确失配指示。每个因子块距离先按该块有效维度计算RMS；组合条件对各块距离等权计算RMS，避免高维块仅因列数更多而支配匹配。

标准化、特征删除和距离均不得读取任何alpha>0响应结果。

## 5. 跨运行匹配

主分析固定为：同一语义目标、不同运行、最近邻 `k=1`。候选选择只读取被冻结的前置条件。每个配置的caliper取其全部查询的最近跨运行前置距离的第90百分位；该值仅由前置距离形成。报告未匹配比例。

敏感性分析固定为：最近邻 `k in {1,3,5}`，caliper分位数 `{0.75,0.90,0.95,1.00}`。不得根据结果选择最优组合。

随机跨运行基线使用相同语义目标和不同运行候选池，以SHA-256稳定种子 `20260806` 进行200次置换。匹配允许参考样本被重复使用，但必须报告唯一参考数和集中度。

## 6. 分解顺序

单因子分析分别使用F1至F7。

增量条件化主顺序冻结为：

`C0 random -> C1 semantic identity -> C2 +F1 -> C3 +F2 -> C4 +F3 -> C5 +F4 -> C6 +F5 -> C7 +F6 -> C8 +F7`。

不得仅依赖该顺序。另执行完整当前集合 `F1+F2+F3+F4+F5` 的逐块删除，以及三种冻结替代加入顺序：`F3,F1,F4,F2,F5`、`F4,F2,F1,F5,F3`、`F5,F3,F2,F4,F1`。

历史主比较必须在同一个F7可用子集上完成：`Current`、`Current+F6`、`Current+F6+F7`，不得改变样本总体。

## 7. 统计单位与判决

点估计按目标匹配计算，但95%区间和置换裁决以无序运行对为聚类单位，另以section/update对作敏感性分析。不得把212个目标当作独立实验重复。

每项结果报告：点估计、95%聚类bootstrap区间（固定2000次、SHA-256稳定种子）、匹配数、覆盖运行数、覆盖运行对数、未匹配率、参考集中度、caliper/k敏感性及逐运行结果。

某因子块仅在下列条件同时满足时记为 `SUPPORTED`：主要形态相似度增量大于零且运行对聚类95%区间下界大于零；至少一个预注册次要响应指标同向；至少三种caliper敏感性设置同向；效应不由不超过两个运行主导。点估计同向但区间跨零或异质时记为 `PARTIALLY_SUPPORTED`。其余记为 `NOT_SUPPORTED` 或 `NOT_EVALUABLE`。

本轮结果只能建立统计条件关系，不能建立因果作用或可执行预测函数。

## 8. 身份残余和幸存反例

身份残余比较在完整当前条件近似匹配后，对照相同语义目标与同target group但不同row identity的跨运行匹配。`sample_id`不得作为特征。

幸存反例定义为：完整当前条件距离通过主caliper，但归一化形态相关性低于0、端点位移方向相反或边界转换类别不同。所有反例保留两侧身份、前置条件、响应、GFG来源引用和未决分类。
