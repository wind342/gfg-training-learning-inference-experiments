# 输入与目标的形成时刻

本表冻结语义边界；完整字段与对象哈希仍须在用户确认后、任何执行前写入 `INPUT_FEATURE_MANIFEST.json`。

| 项目 | 形成时刻 | 可否进入候选 | 说明 |
|---|---|---:|---|
| \(S_t,C_t\) | 当前步开始前的 CSRG 探针完成时 | 是，属于 \(X_t\) | 当前功能前态 |
| \(V_t^-,A_t^-\) | 由 t 以前已建立的 CSRG 状态计算后 | 是，属于 \(X_t\) | 只允许左差分；不得读 \(S_{t+1}\) |
| \(\theta_t\) | 当前训练步开始前的参数版本封存时 | 是，属于 \(X_t\) | 必须绑定版本和 payload 哈希 |
| \(O_t\) | 当前训练步开始前的 Adam `exp_avg/exp_avg_sq/step` 封存时 | 是，属于 \(X_t\) | 不等于未来 Adam 状态 |
| \(\theta_t\times O_t\) 候选 | \(\theta_t,O_t\) 均形成后、当前 batch 开始前 | 是，属于 \(X_t\) | 只能使用预注册变换 |
| 当前 batch 身份/表示 | batch 选择完成、前向开始前 | 是，属于 \(U_t\) | 不允许未来 batch |
| 当前 forward 激活/训练 logits | 当前 batch 前向完成后 | 仅预注册项可进入 \(U_t\) | 必须早于预测密封 |
| raw gradient | 当前 batch backward 完成后 | 是，属于 \(U_t\) | 当前步事实 |
| clipped gradient | 当前裁剪发生后 | 是，属于 \(U_t\) | 当前步事实 |
| Adam 增量 | 当前优化器公式执行并形成增量后 | 是，属于 \(U_t\) | 预测密封以前 |
| actual parameter update | 当前更新张量形成并实际施加后 | 是，属于 \(U_t\) | 任务因此属于“更新后、目标探针前”预测 |
| \(\theta_{t+1}\) | actual update 施加后 | 不计分 | 可由 \(\theta_t\)+update 代数恢复，只验证链条 |
| \(O_{t+1}\) | 当前 Adam 更新完成后 | 不计分 | 原生公式可直接恢复，只验证链条 |
| 候选预测 | 上述当前作用形成后、目标 CSRG 运行前 | 必须密封 | 文件、程序、参数与哈希全部冻结 |
| \(S_{t+1},C_{t+1}\) | 预测密封后的目标 CSRG 探针完成时 | 否，只作目标 | 任何回流均为未来泄漏 |
| \(U_{t+1}\) 及以后 | 后续真实训练步逐步发生时 | 不得提前进入 | 仅在对应步实际到来后用于下一次在线预测 |

局部响应项只有在当前目标步以前已经真实形成，并能在未见运行中按同一合同获得时，才允许进入 `M_local`；否则固定为 `NOT_AVAILABLE`。
