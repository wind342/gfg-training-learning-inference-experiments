# TL-P01 原版 quadratic_complete 在 GNN 与硬脉冲 SNN 上的跨系统预测实测报告

> 执行日期：2026-10-24。评价对象：一次真实训练更新形成之后的具体目标正确性 / 四类能力边界转移。不是完整响应曲线预测，也不是原论文中 TL-P01 的独立训练复现。

## 核心裁决

在训练、读出和组件结构均不同的 GNN 上，原公式的**端点边界分类**成功迁移；在 SNN 的**硬阈值前向**上，准确率较高但对正反能力转移的召回率明显不足。后者是本次预测算法的外推失败，不构成 TLI/TLIR 核心动力学关系的反例。

## 冻结算法、偏置与求导语义

采用原论文 `quadratic_complete` 的相同算式，没有为新系统拟合分类器、重训练一个预测头或使用结果后校准。对每个目标 y 及所有竞争目标 c 计算：

```text
g0 = b_yc · h
g1 = (Δb_yc) · h + b_yc · h'
j  = (Δb_yc) · h'
k  = 0.5 b_yc · h''
predicted_endpoint_gap = g0 + g1 + j + k
post_correct := all competitor gaps > 0
```

因 GNN 与 SNN 的输出头均有 bias，使用 `h̃=(h,1)`、`W̃=[W|bias]` 扩充一维，将仿射头精确转换为原算法中的线性头；这只是代数等价处理。GNN 使用 `torch.func.jvp` 的嵌套前向 AD 严格获得 h'、h''，读取的参数是原始更新前状态与实际已形成更新；SNN 使用原生硬脉冲前向，因此在不位于切换点时真正的局部导数为 h'=h''=0。**绝不把训练时的替代梯度冒充真实方向导数**。

`PREPARE → SEAL → ADJUDICATE` 三阶段强制分离：封存程序只读取 `pretarget` 状态文件，而不读取 post logits 或原生完整结果档案；全部封存后由另一阶段开启原生更新终点。注意原生 SNN 档案在历史上已经存在，故这是算法级顺序封存，不是时间上全新的未知实验。

## 数值响应误差（非主裁决）

主预测目标是各竞争 logit-gap 的**符号**。为了避免把高准确率误读为完整响应预测，额外报告预测最小竞争间距与真实终点 margin 的 RMSE：

| 系统 | 不更新基线 RMSE | linear RMSE | quadratic_complete RMSE |
|---|---:|---:|---:|
| GNN | 0.7042 | 0.7306 | 0.9617 |
| SNN | 0.8313 | 0.8134 | 0.8134 |

GNN 的二阶算式显著改善了四类跨越判断，但 RMSE 不优于一阶算式。它不是精确求出完整有限幅度响应曲线的实证证据。

## 独立校验与防泄漏边界

- GNN 原训练按原代码重放，检查了四个正式检查点的接收状态、真实 update 与终点参数哈希，全部匹配先前冻结记录；SNN 四种子的原生参数及更新与历史档案哈希匹配。
- 固定目标集：GNN 每个事件 256 个独立留出图；SNN 每个事件 450 个原测试数字。共 28 个真实更新事件，10,272 个独立身份-事件记录，无选择性排除。
- 预计算和封存只读取更新前参数、实际更新、预指定目标与预状态方向量；记录保存 `PREDICTIONS_SEALED.json` 和原始 SHA-256。读出 post 参数及其 logits 在独立 adjudicate 阶段进行。
- 校验器不信任原报告指标，而是重新读取原生 post 参数执行网络前向，重新匹配目标身份和四类真实转移，逐一核对前后哈希与目标结果。
- 完整 GFG Core v3 未接入；本次不作为正式原生 GFG 实验复现。

## 原样保留的局限

1. 本次是对已知方法与历史保存系统的跨系统转用，SNN 的原生轨迹历史上已经存在；不得称其为独立研究组全新盲测。
2. SNN 真实前向的离散脉冲跨阈值跳跃无法由固定受点的有限阶局部导数完整表示，这是本次预测算法的适用边界；训练中使用的 surrogate gradient 不等于真实导数。
3. GNN 原始训练脚本未保存参数快照；本次按原 seed 和训练代码确定性重放，并按历史 SHA-256 确认身份。
4. 原算法专门用于分类正确性与目标竞争间隙。其他任务的边界需在实验前冻结，不可借用本结果随意外推。
5. 这不是原始 TLIR 全体关系或 GFG 全套能力的裁决，只是 TL-P01 预测算法在两套额外系统的单步边界预测能力测试。
