# 图神经网络 GNN 对 TLI/TLIR 核心关系的独立反证压力测试

**实验类型：** 新增系统的实际 PyTorch 计算、先冻结正式协议、三种子正式裁决。不是原论文实验的复现，也不是 GFG Core v3 完整证据链。

## 科学问题

在与已报告的 nanoGPT、ResNet、Diffusion 体系不同的**四层残差消息传递 GNN**中，已冻结的 TLI 功能关系能否经真实参数更新、接收状态交换、组件联盟门控及回滚保持？如某一关系的冻结门槛失败，必须保留其失败。

**不能通过本实验直接检验的关系：** Reinforcement/Feedback closure；因为任务使用监督学习，没有环境反馈闭环。不能声称检验了完整 TLIR。

## 实际系统与冻结阶段

- 图：12 节点无向 Erdős–Rényi 图，边概率在 0.13～0.37 之间变化；两个具有稳定语义身份的标记节点，非锚点随机重排。
- 任务：判断标记目标节点是否距离锚点不超过两跳；图拓扑和节点身份共同决定真实标签。
- 模型：40 维隐藏状态、四层残差消息传递、只从锚点读出；从随机初始化训练。
- 优化：RMSprop，学习率 0.003，500 次真实更新，批量 64。每种子 1,024 个训练图、256 个独立测试图。
- 先在完全分离的 pilot seed=99999 运行不参与正式裁决的试跑。固定代码与判据后才执行正式种子 20261024、20261025、20261026。
- 正式采样步 25、100、200、350；receiver/update 对固定为 (100←25)、(200←100)、(350←200)。
- 组件干预使用全部 16 个 coalition mask，计算真实目标 margin 的四人 Shapley。**它不是原 CSRG-4C 的 12-forward 方案**；这是跨系统实验的 16-mask 设计。
- 非加性直接计算完整两个 logits 的差分（不借助 margin 竞争者选择）。

**冻结协议 SHA-256：** `e2bd6b803c20df9bc3e612edc931631df4b8ec14016b2db1fb5fc5a321932085`  
**实验源码 SHA-256：** `28e9b9d8d611c05fa3b6a45b89f359181c6d83ef21d4fb8681f85e4d6ab5a722`

**正式结果与重新执行的 SHA-256：** `5579099e40bc605dec076134ab7393b936411b6bc18d286166a1d525a523de47`

独立 `gnn_independent_checker.py` 复核原始协议、结果身份、三个种子、固定采样检查点以及九项门槛的重新汇总。结果为 **PASS**。它不是对缺失的所有原始中间 tensor 的独立来源核验；完整训练由原生重复运行给出。

## 哪些结论有资格成立

1. 已在一个新的、受控的图学习体系中观察到：同一实际更新的响应可以依赖接收参数状态；真实更新可以改变测得的功能支撑；冻结模型输出依赖具体组件版本，并具有查询依赖和非加性交互。
2. 固定非线性比例门槛未在所有正式种子通过。这是准确保留的局部负结果，说明不同种子和训练阶段中的有限振幅非线性**发生频率**具有强差异。
3. 不能从一个 seed 的非线性频率门槛失败，推出已被别的 seed 真实观察到的有限响应非线性根本不存在；同样不能把本次结果当作 TLIR 普遍正确的证明。
4. 本实验**没有**检验 R/feedback closure，也没有展示大模型尺度或真实复杂图数据集的普适性。GFG 原生事实图与 Core v3 严格验证未接入；该实验使用严格的代码、状态及结果哈希，不能冒称 GFG 完整可审事实链。
5. 一个可证伪统一理论必须允许类似本次负结果进入正式裁决，不能事后改变判据。

## 文件说明

`gnn_tlir_counterexample.py`：源代码（含训练及正式的原生干预），`gnn_falsification_frozen.json`：正式前冻结的阈值与范围，`gnn_tlir_formal_results.json`：完整数值与每种子结果，`gnn_tlir_formal_replay.json`：第二次运行结果，`gnn_independent_checker.py` 和 `gnn_falsification_audit.json`：汇总检查，`gnn_graph_negative_controls.py` 和其结果：后加对照，`gnn_tlir_pilot.json`：隔离试跑。

**复现命令：** 在 Python + PyTorch + NumPy 环境（本次 PyTorch 2.10.0+cpu）中运行 `python gnn_tlir_counterexample.py --formal --output gnn_tlir_formal_results.json`。目前正式脚本以 `/mnt/data/gnn_falsification_frozen.json` 为冻结协议路径；若从别的目录复现，需保持相同目录布局或在运行副本中显式调整协议路径，并注明任何调整不会是完全同源 SHA 的重跑。
